# SmartLoan Predictor — Phase 1 Planning Documents

This package contains initial planning drafts for SmartLoan Predictor, prepared from the decisions discussed so far.

## Contents

- `PRD.md` — product scope and goals
- `SRS.md` — functional/non-functional requirements and acceptance criteria
- `SYSTEM_ARCHITECTURE.md` — service responsibilities and request flows
- `API_CONTRACT.md` — proposed API boundaries and payload shapes
- `DATABASE_DESIGN.md` — conceptual PostgreSQL design
- `DECISION_REGISTER.md` — confirmed choices, proposals, and open decisions
- `ANTIGRAVITY_HANDOFF_PROMPT.md` — scoped prompt to review/integrate these documents in Google Antigravity

## Status and caveats

These are draft documents, not evidence that code, a dataset, a trained model, or a deployed system exists. The dataset, target label, final prediction fields, model, explanation method, probability policy, authentication mechanism, retention policy, quantitative SLOs, and final ML hosting decision remain open.

Review these documents before implementation. Do not treat placeholders or illustrative JSON as final API schemas.
